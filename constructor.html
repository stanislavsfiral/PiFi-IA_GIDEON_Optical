🛠️ Верхняя панель сборки

• ➕ / 📋 / 🔗 / 🗑️: добавить сфираль, дублировать, соединить две сфирали швом, удалить.
• ↩️ / ↪️: отменить или вернуть последнее действие.
• 3D / T / F / S: переключение ракурсов (3D, Сверху, Спереди, Сбоку).
• ↕ / ↻: окна точного ввода координат XYZ и углов поворота.
• 👁️ (правый верхний угол): скрыть весь интерфейс для чистой записи видео.

⚙️ Меню «Инструменты»

• 🧬 Подуровни: позволяет кликать отдельно по правому/левому витку или S-переходу.
• 🧲 Выровнять по сетке: привязывает координаты и углы к шагу сетки.
• 🌀 Фрактал / Уолш / ✨ Резонанс: генерация фрактальной структуры, фазовая кодировка и запуск волны.
• 🧹 Пересобрать связи / 🔬 Оптика: проверка швов и расчёт интерференции.

🧠 Меню «ИИ»

Работает при запущенном локальном сервере py sfiral_server.py: задаёт вопросы по графу, сохраняет термины, проверяет инварианты Нейроядра и запускает обучение агента.
